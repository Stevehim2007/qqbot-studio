安全提示与免责声明

不收集、不保存 QQ 密码；现代 QQ 需要扫码登录。如果扫码后要求设备验证、短信验证、滑块或安全验证，必须在 noVNC 里按 QQ 官方提示操作；工具不能绕过验证。

账号风险：第三方协议端存在账号风控/封禁风险，使用小号，遵守 QQ 协议与当地法律。

密钥边界：DeepSeek API Key 仅写入本机 AstrBot 配置，不写入浏览器存储，也不在控制台中显示。
