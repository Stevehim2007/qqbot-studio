# 本地点歌目录

把你有权使用的本地音频放在本目录，然后由 QQ 用户发送：

```text
/唱歌
/唱歌 文件名关键词
/点歌
/点歌 文件名关键词
```

插件按文件名匹配（只扫描本目录直属文件，不递归、不跟随符号链接），随机或匹配后使用 AstrBot `Comp.Record.fromFileSystem(...)` 发送。不调用 LLM、不调用 TTS/音乐生成服务，因此不会消耗模型 token。

支持扩展名：

```text
.mp3 .wav .ogg .flac .m4a .aac
```

**本仓库不附带任何版权歌曲。** 请自行确认音频授权；跨平台能否播放还取决于 QQ 协议端/AstrBot 适配器对音频格式的支持。部分平台/适配器可能只接受 WAV，建议优先使用 WAV 或由管理员预先转码。

管理员可在 WebUI 配置 `song_enabled`、群/用户冷却、最大文件大小和提示文案。单文件默认上限 20 MB。
